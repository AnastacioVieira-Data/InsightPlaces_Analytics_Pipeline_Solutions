# 🇬🇧 English Version

## 📊 InsightPlaces Analytics Pipeline Solutions

### 🚀 About the Project
This fictitious project for **InsightPlaces**, an online booking management and administration platform, integrates the industry's most essential data analysis tools: **SQL, Python, and Power BI**. Furthermore, project management and monitoring follow the **Kanban** methodology to ensure agile delivery, transparent task tracking, and efficient workflow organization.

- **Project Status:** Under Development 🚧
- **Current Phase:** Python-based database refactoring. Future steps include creating advanced SQL views and building an actionable executive dashboard in Power BI for InsightPlaces stakeholders.

---

### 🛠️ Technology Stack & Architecture
1. **SQL (Database Foundation & DDL/DML Operations)**
2. **Python (Data Extraction, Cleaning, Automation, Database Refactoring & Predictive Modeling via Scikit-Learn)**
3. **Power BI (Executive Dashboards & Strategic Business Intelligence)**

---

### ✅ Completed Work (SQL Phase)
- Designed and established the relational database architecture.
- Created and altered tables using `CREATE TABLE` and `ALTER TABLE`.
- Performed record updates and data manipulation using `UPDATE`.
- Implemented database backups (Dumps) and investigated cross-table dependencies.
- Managed secure data deletion using `DELETE` while strictly respecting parent-child foreign key constraints and procedural order.

---

### 🔮 Upcoming Phases
- **Python:** Data extraction, cleansing, automation, database refactoring, and predictive modeling scripts utilizing the `scikit-learn` library.
- **Power BI:** Comprehensive strategic dashboard design featuring actionable business insights.

# 🇧🇷 Versão em Português

## 📊 InsightPlaces Analytics Pipeline Solutions

### 🚀 Sobre o Projeto
Este projeto fictício da **InsightPlaces**, uma plataforma de administração e gerenciamento de reservas online, visa a integração do uso das ferramentas de análise de dados mais importantes do mercado: **SQL, Python e Power BI**. Ademais, para o monitoramento e gestão eficiente do projeto, é utilizada a metodologia **Kanban**.

- **Status do Projeto:** Em Desenvolvimento 🚧
- **Fase Atual:** Atualmente trabalhando na fase de refatoração do Banco de Dados por meio do Python, com etapas futuras voltadas à criação de *views* no SQL e de um dashboard com estratégias acionáveis para a empresa no Power BI.

---

### 🛠️ Pilares Tecnológicos & Arquitetura
1. **SQL (Fundação do Banco de Dados e Operações DDL/DML)**
2. **Python (Extração, Limpeza, Automação, Refatoração do Banco de Dados e Modelagem Preditiva com Scikit-Learn)**
3. **Power BI (Dashboards Executivos e Inteligência de Negócios Estratégica)**

---

### ✅ O que já foi feito (Fase SQL)
- Criação e estruturação do banco de dados relacional.
- Criação e alteração de tabelas utilizando `CREATE TABLE` e `ALTER TABLE`.
- Atualização e manutenção de registros utilizando `UPDATE`.
- Realização de backups (Dumps) e investigação aprofundada de dependências entre tabelas.
- Exclusão segura de dados utilizando o comando `DELETE`, seguindo rigorosamente a ordem do procedimento pai-filho (restrições de chave estrangeira).

---

### 🔮 Próximas Etapas
- **Python:** Extração, limpeza de dados, automação, refatoração do banco de dados e script de previsão/Machine Learning utilizando a biblioteca `scikit-learn`.
- **Power BI:** Construção de dashboard estratégico para tomada de decisão.
